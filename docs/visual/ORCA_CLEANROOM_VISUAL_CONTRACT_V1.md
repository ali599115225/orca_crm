## 1. السلطة وحدود إعادة الاستخدام

القرار الأحدث المعتمد في المحادثة ثم الطلب الحالي يعلوان على المقترحات السابقة وعلى قواعد الهوية القديمة. هذا العقد يثبت القرارات ولا يعيد فتحها. أي تغيير لاحق على القيم أو الاستثناءات يحتاج موافقة المستخدم الصريحة.

الواجهة الجديدة تُبنى من الصفر: **no old visual mappings reuse except login exception**. قراءة المصدر لاستخراج القيم ومطابقة تكوين كرت العنوان لا تعني نسخ CSS أو aliases أو مكونات أو طبقة توافق قديمة. لا تُنقل خرائط `ds-* / orca-* → nc-*` ولا طبقة الألوان التشغيلية القديمة إلى الواجهة الجديدة.

### الاستثناء الوحيد: صفحة تسجيل الدخول

تُنقل لاحقًا صفحة تسجيل الدخول كاملة **كما هي تمامًا بلا تعديل بصري أو وظيفي**: الملفات والألوان والمقاسات والتفاعلات ومنطق الدخول والتحقق والأخطاء وإعادة التوجيه. يُنقل معها فقط ما تحتاجه من تبعيات بصرية مباشرة، دون سحب بقية الطبقة البصرية القديمة أو تعميمها على التطبيق.

لا تُعاد مواءمة صفحة الدخول مع هذا العقد، ولا تُنظف تأثيراتها أو ألوانها ضمن النقل. أي تعديل عليها يتطلب طلبًا مستقلًا. هذا هو الاستثناء الوحيد من منع نقل الهوية القديمة، وليس كرت العنوان استثناءً ثانيًا لنسخ التنفيذ.

**main content full-width** داخل كل المساحة المتبقية بعد Sidebar، و**no centered max-width container**. لا أعمدة فارغة ولا فراغ جانبي مصطنع: **no dead space**. تتمدد الشبكات والكروت لاستغلال العرض؛ المسافات المعتمدة فقط للحماية البصرية والفصل.

**card height follows content**؛ المقاسات الصريحة للعناصر مثل KPI والحقول لا تعمم على بقية الكروت. **no nested vertical scroll**: الصفحة تتمدد وتملك التمرير الرأسي، دون تمرير رأسي داخلي للكروت والجداول الرئيسية. **لا Glow افتراضي، ولا Glass blur**؛ لا تُستعاد هذه التأثيرات من المصدر.

- يمكن أن يزداد التأثير قليلًا عند Hover التفاعلي، مع التقويس نفسه.

### KPI

- Padding **12px** وRadius **10px**.
- المحتوى centered أفقيًا وعموديًا؛ الرقم الأبرز مع اسم المؤشر وسطر ثانوي واحد عند الحاجة.
- توزيع متساوٍ يستغل العرض المتاح دون عرض ثابت لكل كرت أو فراغ سفلي.
- Hover ذهبي خفيف ومقوس فقط إذا كان الكرت تفاعليًا.

## 7. الأزرار والحقول والنماذج

- الزر النصي **120 × 40px**؛ زر الأيقونة **40 × 40px**. عرض الزر ثابت ولا يتغير بطول النص، وتلتف مجموعة الأزرار عند ضيق العرض.
- Primary ذهبي ممتلئ بنص داكن؛ Secondary سطح محايد وحد محايد ونص أساسي حسب الوضع؛ Ghost بلا تعبئة ونص أساسي؛ Destructive أحمر للإجراء الخطر فقط.
- Hover ذهبي مقوس فقط؛ الأزرار والحقول ذات تقويس موحد ضمن النطاق المطروح **8–10px** دون اختلافات عشوائية.
- Input / Select / Search / Date بارتفاع **40px** وبنفس الحدود والتقويس وPadding؛ يتغير العرض فقط حسب الشبكة.
- Textarea استثناء الارتفاع لأنه متعدد الأسطر، مع الحفاظ على هوية الحقول.
- Forms بعرض المساحة المتاحة، Grid يستغل المحتوى، عنوان ووصف أعلى الحقول، وأزرار الحفظ والإلغاء **120 × 40px**.
- رسالة التحقق قرب الحقل وأسفله مباشرة بلون الحالة؛ لا Toast بديل عن خطأ النموذج.
- على Mobile تصبح النماذج عمودًا واحدًا دون تصغير الحقول.

## 8. الجداول والتبويبات والتحديد

### Tables

- Full-width، والأعمدة تستغل كامل العرض؛ جدول متماسك دون كرت مستقل لكل صف.
- Header **40px** والصف **40px**.
- فواصل خفيفة **1px** وإطار خارجي Radius **10px**.
- **no zebra**؛ Hover ذهبي خفيف ومقوس على الصف، دون زوايا مربعة.
- **no inner vertical scroll**؛ نمو الجدول ضمن تمرير الصفحة.
- على Mobile فقط يسمح بتمرير أفقي عند الحاجة؛ لا تمرير أفقي داخلي على Desktop/Tablet.

### Tabs

- Full-width وتوزيع متساوٍ دون فراغ جانبي.
- Active: نص ذهبي + خط سفلي ذهبي **2px**، بلا تعبئة ذهبية كاملة.
- Hover ذهبي مقوس؛ لا تمرير داخلي على Desktop/Tablet.
- على Mobile فقط يسمح بتمرير أفقي عند عدم كفاية العرض.

### Selected rows

خلفية Gold soft مع حد Gold border **1px ثابت** وتقويس واضح. تبقى حالة التحديد بعد انتهاء Hover، ولا تستخدم تعبئة ذهبية كاملة.
