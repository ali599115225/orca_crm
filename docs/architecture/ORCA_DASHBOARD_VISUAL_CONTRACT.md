## 1. الفلسفة والمبادئ الحاكمة (Core Principles)

1. **الصفحة المرجعية الذهبية (Golden Reference Page):** تعتبر لوحة القيادة التشغيلية هي المرجع المعياري الأعلى لجميع واجهات ORCA في التوازن، وانعدام التمرير الخارجي، وتطابق اللغتين، والتفاعل الحركي.
2. **منع التمرير الخارجي التام (Zero External Scroll):**
   - ممنوع ظهور شريط تمرير رأسي على الصفحة عند شاشات العمل القياسية (1440x900).
   - قفل الحاوية الخارجية إجبارياً عبر محدد المسار (`:has([data-dashboard-cleanroom-root])`) لمنع أي اهتزاز أو تحرك بعجلة الفأرة.
3. **التمرير الداخلي المحصور (Internal Scroll Boundary):**
   - أي محتوى إضافي يتجاوز الارتفاع الرأسي المصمم يجب أن ينساب داخل حاويته حصراً (`overflow-y: auto`) بشريط تمرير أنيق ونحيف (`scrollbar-width: thin`).
   - بقاء أزرار الإجراء والفوتر (`cardFooterLink`) ثابتة وظاهرة في قاع الكرت دائماً دون أن تتأثر بالتمرير.
4. **التطابق اللغوي الكامل والتكافؤ الأصيل (100% Bilingual Parity):**
   - اللغة العربية والإنجليزية متكافئتان بالكامل.
   - يمنع منعاً باتاً ظهور أي كلمة أو عنوان أو حالة عربية عند اختيار اللغة الإنجليزية (`EN`).
   - يمنع ظهور نصوص إنجليزية شاذة أو غير معربة في الواجهة العربية (`AR`).
   - الأرقام التشغيلية لاتينية (`bdi dir="ltr"`) والتواريخ ميلادية قياسية (`dd/mm/yy`).
5. **انعدام القفزات البصرية (Zero Cumulative Layout Shift - CLS = 0.000):**
   - شاشة التحميل الأولية (`loading.tsx`) يجب أن تكون مرآة هندسية مطابقة بنسبة 100% لأبعاد وشبكة الصفحة الحقيقية، للقضاء على أي وميض أو انزياح عند تحميل البيانات.

## 2. الهيكلية المعمارية وشبكة التوزيع (Grid & Layout Architecture)

### أ. نسب الأعمدة المتوازنة (Grid Columns)
```css
.row {
  min-width: 0;
  display: grid;
  grid-template-columns: minmax(0, 1.45fr) minmax(320px, 0.95fr);
  align-items: stretch;
  gap: 10px;
}
```
* **العمود الرئيسي (60%):** يستوعب مسار الصفقات ومركز العمليات اليومية.
* **العمود الجانبي (40%):** يستوعب حالة الوكلاء ومركز القرار الذكي.
* **خاصية Stretch الإلزامية:** يجب أن يتساوى ارتفاع الكرتين المتقابلين في كل صف بفرق `0.0px`.

### ب. قياسات الصفوف والكروت (Card Heights Benchmark)
* **الصف الأول (مسار الصفقات + حالة الوكلاء):** الارتفاع القياسي المستهدف `~225px` إلى `~240px`.
* **الصف الثاني (مركز العمليات + مركز القرار):** الارتفاع القياسي المستهدف `~310px` إلى `~325px`.
* **محاذاة خط القاع:** يتوازى قاع كروت الصف الثاني طبيعياً مع قاع عناصر السايدبار (عند `Y ≈ 830px - 880px`).

## 3. مواصفات المكونات البصرية الدقيقة (Component Specifications)

### 1. بطاقات المؤشرات العلوية (KPI Grid)
* ارتفاع مدمج موحد (`~64px`).
* شريط لمسة ذهبية علوي رفيع (`border-top: 2px solid var(--nc-accent)`).
* حاويات الأيقونات بخلفية رقيقة ولمسة ذهبية فخمة.

### 2. مسار الصفقات (Deal Spine Card)
* **تمدد المسار:** إزالة أي قيود عرض ضيقة (`width: 100%`) مع هوامش متناسقة (`padding: 8px 16px`).
* **الهوفر المقوس:** حواف مقوسة ناعمة (`border-radius: 12px / 14px`) مع تأثير تركيز بيضاوي وظل خفيف (`box-shadow: 0 0 0 1px var(--nc-op-blue-border)`) وممنوع منعاً باتاً المربعات الحادة.
* **خط المسار:** خط وسطي متصل بين الدوائر الخمس مع خلفية متدرجة تبرز المراحل النشطة ونسبة الإغلاق.

### 3. حالة الوكلاء (Agents Status Card)
* شبكة خلايا متوازنة (`2 columns x 3 rows`).
* ارتفاع الخلية المدمج (`min-height: 28px`) مع حواف مقوسة (`border-radius: 8px`).
* نقاط الحالة الدلالية: الأخضر للنشط، الكهرماني للمتابعة، والأحمر للفشل.

### 4. مركز العمليات اليومية (Daily Operations Card)
* دمج التابات في صف الهيدر العلوي لتقليص الهدر الرأسي.
* صفوف المهام:
  * الوقت المجدول (`timeLeading`) في بداية السطر.
  * عنوان المهمة مترجم بالكامل حسب لغة النظام.
  * اسم العميل والوكيل متصل بفاصل نقطي (`·`).
  * البادجات الدلالية الكبسولية على الطرف الآخر.
  * **الحدود الانسيابية:** حدود شفافة عادية مع فاصل سفلي خفيف، وحواف مقوسة ناعمة (`border-radius: 10px`).
  * **الهوفر:** خلفية زرقاء ناعمة (`var(--nc-op-blue-soft)`) بإطار مقوس أزرق أنيق.
* قائمة التمرير الداخلي: `max-height: 230px; overflow-y: auto;` مع تثبيت فوتر "عرض جميع المهام" بالأسفل.

### 5. مركز القرار الذكي (Intelligent Decision Center)
* عرض 4 إلى 5 مؤشرات تشغيلية حقيقية مع إمكانية التمرير الداخلي.
* صفوف بارتفاع `40px` بحواف مقوسة (`border-radius: 10px`).
* تطابق تام في الألوان واللغات بين الإشارات والوكيل المعني.

## 5. بوابة الإغلاق والاعتماد (Closure Verification Gate)

لا تغلق أي صفحة جديدة أو معدلة في النظام إلا باستيفاء الشروط التالية:
1. **اختبار التمرير الخارجي:** `outerPageScrollTop === 0` مع تدوير عجلة الفأرة.
2. **اختبار الرؤية الكاملة:** ظهور الفوتر وأزرار الإجراءات داخل الشاشة بدون تحريك (`visibleInViewport === true`).
3. **اختبار التكافؤ اللغوي:** خلو النسخة الإنجليزية من أي أحرف عربية (`0 Arabic characters in EN mode`) والعكس.
4. **اختبار الـ CLS:** أن تكون شاشة `loading.tsx` مطابقة بنسبة 100% ولا تحدث أي قفزة بصرية.
5. **اختبار الحوكمة:** اجتياز `npm run lint` وجميع اختبارات `vitest` بنسبة نجاح 100%.
