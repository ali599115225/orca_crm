# تقرير بوابة المالك — ORCA Owner Portal MVP

## الملفات التي تم بناؤها

- `app/dashboard/owner-portal/page.tsx` — صفحة بوابة المالك الرئيسية (Server Component)

## المكونات المنشأة

### 1. عرض العقارات (Properties View)
- يعرض جميع الوحدات (Units) المرتبطة بالمنشأة من جدول `Unit`
- يربط كل وحدة بالمشروع (Project) والعقد (Contract) إن وجدت
- جدول تفصيلي يضم: رقم الوحدة، المشروع، النوع، السعر، الحالة، المالك (اسم المشتري)

### 2. نظرة عامة على الإيرادات (Revenue Overview)
- **إجمالي قيمة العقود**: مجموع `totalVolumeSar` من جميع العقود (Contracts)
- **إيرادات الإيجار**: مجموع `totalAmount` من فواتير الإيجار (RentalInvoice)
- **الأقساط المحصلة**: مجموع المبالغ المدفوعة من الأقساط (Installment حيث `paymentStatus = Paid`)
- **تحليل شهري**: رسم بياني شريطي للإيرادات الشهرية لآخر 6 أشهر

### 3. لوحة الإشغال (Occupancy Dashboard)
- إحصاءات: إجمالي الوحدات، الوحدات المشغولة (التي لها عقد)، الوحدات الشاغرة
- نسب مئوية مع شريط تقدم مرئي
- الألوان: أخضر للمشغولة، كهرماني للشاغرة

### 4. العقود (Contracts)
- جدول العقود: رقم العقد، المشتري، الوحدة، المشروع، القيمة، الحالة
- حالة العقد: نشط / غير نشط مع ألوان مميزة

### 5. حالة الصيانة (Maintenance Status)
- عرض بلاغات الصيانة (MaintenanceTicket) المرتبطة بممتلكات المالك
- جدول: العنوان، الفئة، الأولوية، الحالة، الفني المعين، التكلفة

## نماذج البيانات المستخدمة

| الموديل | الاستخدام |
|---------|-----------|
| `Unit` | الوحدات العقارية وعلاقتها بالمشاريع والعقود |
| `Project` | أسماء المشاريع |
| `Contract` | عقود البيع (المالك = المشتري في العقد) |
| `Installment` | الأقساط المدفوعة لتحليل الإيرادات الشهرية |
| `RentalLease` | عقود الإيجار النشطة |
| `RentalInvoice` | إجمالي إيرادات الإيجار |
| `MaintenanceTicket` | بلاغات الصيانة (موديل جديد) |

## النمط البرمجي
- Server Component مع `async` وجلب البيانات مباشرة عبر `prisma`
- استخدام `getActiveTenant()` لتحديد المنشأة
- واجهة عربية كاملة مع اتجاه RTL
- استخدام فئات CSS من NovaCore الموجودة (`nc-glass`, `nc-surface-strong`, إلخ)
