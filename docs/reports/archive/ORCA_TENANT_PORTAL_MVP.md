# تقرير بوابة المستأجر — ORCA Tenant Portal MVP

## الملفات التي تم بناؤها

- `app/dashboard/tenant-portal/page.tsx` — صفحة بوابة المستأجر الرئيسية (Server Component)

## المكونات المنشأة

### 1. عقد الإيجار الخاص بي (My Lease)
- عرض جميع عقود الإيجار (RentalLease) للمنشأة
- بطاقة لكل عقد: اسم الوحدة، اسم المستأجر، تاريخ البداية والنهاية، قيمة الإيجار، التأمين
- شريط تقدم للمبالغ المدفوعة مقابل المتبقية
- حالة العقد: نشط / منتهي / ملغي

### 2. فواتيري (My Invoices)
- جدول فواتير الإيجار (RentalInvoice): رقم الفاتورة، تاريخ الإصدار، تاريخ الاستحقاق، الإجمالي، الحالة
- تصنيف حسب الحالة: مدفوعة / غير مدفوعة / متأخرة
- عداد إحصائي للفواتير حسب كل حالة

### 3. المدفوعات (Payments)
- سجل معاملات الدفع (PaymentTransaction): تاريخ الدفع، المبلغ، الرسوم، الصافي، طريقة الدفع، الحالة
- ترجمة طرق الدفع: تحويل بنكي، بطاقة

### 4. طلبات الصيانة (Maintenance Requests)
- جدول بلاغات الصيانة (MaintenanceTicket): العنوان، الفئة، الأولوية، الحالة، الفني، التكلفة، التاريخ
- ترجمة عربية للفئات (كهرباء، سباكة، تكييف، إنشائي، أخرى)
- ترجمة عربية للأولويات (عاجل، متوسط، منخفض) والحالات (معلق، قيد التنفيذ، مكتمل)

### 5. المستندات (Documents)
- قسم يعرض مستندات العقود المتاحة
- بطاقات لكل عقد مع أيقونة مستند
- معلومات: اسم الوحدة، المستأجر، تواريخ العقد

## مؤشرات الأداء الرئيسية (KPIs)
- عدد عقود الإيجار النشطة
- إجمالي المبالغ غير المدفوعة (بالريال)
- إجمالي المدفوعات المسددة
- عدد طلبات الصيانة المعلقة

## نماذج البيانات المستخدمة

| الموديل | الاستخدام |
|---------|-----------|
| `RentalLease` | عقود الإيجار وتفاصيلها |
| `RentalInvoice` | الفواتير المرتبطة بالإيجار |
| `PaymentTransaction` | سجل المدفوعات |
| `MaintenanceTicket` | طلبات الصيانة (موديل جديد) |

## النمط البرمجي
- Server Component مع `async` وجلب البيانات مباشرة عبر `prisma`
- واجهة عربية كاملة مع اتجاه RTL
- استخدام فئات CSS من NovaCore
- تنسيق متجاوب (responsive) مع نظام grid
