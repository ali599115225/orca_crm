1 لوحة التحكم (Dashboard) ✓ مفعّل وقاعدة بيانات app/operations/dashboard/page.tsx app/operations/dashboard/DashboardView.tsx علاقات Prisma:
Lead, Project, Task, Contract, User 		متصل بالكامل. يجمع مؤشرات الأداء الأساسية (KPIs) ديناميكياً من الجداول. يضم نظام تنبيهات حية وحسابات مؤتمتة لتوقعات الـ AI (أوقات الاتصال الفضلى، المستشارين الذين يحتاجون للدعم) بناءً على خوارزميات محتسبة في كود الصفحة.
2 العملاء المحتملين (Leads) ✓ مفعّل وقاعدة بيانات app/operations/leads/page.tsx components/views/tabs/LeadsTabs.tsx components/views/pipeline/Pipeline.tsx components/views/tabs/Contacts.tsx components/views/tabs/Opportunities.tsx علاقات Prisma:
Lead, Contact, Opportunity, Tour, Offer, Task
APIs:

3 المشاريع العقارية (Projects) محاكاة تفاعلية بالذاكرة app/operations/projects/page.tsx components/views/ProjectsView.tsx لا يوجد (بيانات وهمية)
initialProjects 		محاكاة محلية. الواجهة تفاعلية بالكامل وتسمح للمستخدم بالبحث وتصفية المشاريع وحجز الشقق وإضافة مشروع جديد، ولكن العمليات تتم في ذاكرة المتصفح (React State) فقط ولا يتم حفظها في قاعدة بيانات Prisma.
4 العقارات (Properties) محاكاة تفاعلية بالذاكرة app/operations/properties/page.tsx components/views/PropertiesView.tsx لا يوجد (بيانات وهمية)
initialProperties 		محاكاة محلية. تتيح الواجهة إدارة وتتبع حالة الوحدات السكنية (حجز، بيع، تسليم) وحساب فروقات الأسعار للمشترين محلياً بالكامل. لا توجد قراءة أو كتابة من جدول الوحدات العقارية بقاعدة البيانات.
5 العقود والمدفوعات (Rental) محاكاة تفاعلية بالذاكرة app/operations/rental/page.tsx لا يوجد (بيانات وهمية)
initialLeases, initialInvoices 		محاكاة بالكامل. شاشة متقدمة تحاكي دورة حياة الإيجار وعقد إيجار الموحد. تشمل تسجيل عقود، توليد فواتير آلية، محاكاة الدفع، ومطابقة كشوف الحسابات البنكية (Reconciliation) برفع ملفات وهمية، وتوليد تسويات الملاك. كل التعديلات تزول عند التحديث.
6 حاسبة التمويل السكني ✓ مفعّل برمجياً بالكامل app/operations/calculator/page.tsx components/views/CalculatorView.tsx منطق حسابي محلي مستقل (Client-side) مفعّل بالكامل. حاسبة تمويل عقاري متطورة جداً تحاكي التمويل لأكثر من 10 بنوك سعودية، وتحسب الدعم السكني (سكني)، وتفحص مدى مطابقة التمويل لتعليمات مؤسسة النقد العربي السعودي (SAMA DSR). لا تحتاج للاتصال بقاعدة البيانات لعملها.
7 العروض العقارية (Offers) نموذج تفاعلي متصل بـ API app/operations/offers/page.tsx components/views/OffersView.tsx APIs:
/api/properties 		بيانات API وهمية. يقوم المكون بجلب قائمة الوحدات المتاحة لعرضها، ولكن ملف الـ API يرجع مصفوفة بيانات ثابتة من الذاكرة ولا يستعلم من جداول قاعدة البيانات. إرسال طلبات التواصل وحجز المعاينة تتم محاكاتها محلياً فقط.
8 الجولات العقارية (Tours) نموذج تفاعلي متصل بـ API app/operations/tours/page.tsx components/views/ToursView.tsx APIs:
/api/properties 		بيانات API وهمية. يعرض العقارات التي تحتوي على جولات افتراضية مع تضمين مشغل 360 درجة وجدولة مواعيد للزيارات الميدانية. يستعلم من API العقارات الوهمي ولا يحفظ بيانات حجز الجولات بقاعدة البيانات.
9 الإعلان والتسويق (Marketing) واجهة عرض ثابتة app/operations/marketing/page.tsx components/views/MarketingView.tsx لا يوجد تصميم ثابت فقط. يعرض بطاقات تشير إلى قنوات الربط الرقمي العقارية (Noon, Bayut, Property Finder) وإحصائيات إرشادية حول الإنفاق والاستحواذ. لا توجد أي وظائف تفاعلية أو حفظ للبيانات.
10 الحملات (Campaigns) واجهة عرض ثابتة app/operations/campaigns/page.tsx components/views/CampaignsView.tsx لا يوجد تصميم ثابت فقط. يعرض جدولاً يوضح أداء 4 حملات تسويقية افتراضية (ميزانية، عملاء، تكلفة الاستحواذ) مع بطاقات إرشادية للمؤشرات. لا يدعم المكون الحفظ أو التعديل أو استيراد البيانات الفعلية.

Server Actions:
إجراءات الدفع، وإدارة المستخدمين، وحالة المطابقة القانونية 		متصل بالكامل. لوحة تحكم حية متطورة للغاية لإدارة الشركة (الاسم، الباقة، الفواتير، الترقية الفورية)، وإدارة مستخدمي وموظفي المنشأة العقارية (إنشاء، تعديل، حذف)، وإدارة إقرارات واتفاقيات الربط مع الجهات الحكومية ومطابقتها.

الخلاصة المعمارية: يظهر من فحص الكود المصدري وجود تباين برمجى واضح؛ فالنظام مجهز بالكامل من الناحية الإدارية والتحليلية وأدوات الحوكمة والذكاء الاصطناعي ومركز العملاء الأساسي والمهام وقنوات الاتصال والدعم وتذاكر الموظفين. بينما تظل النماذج والعمليات العقارية التفصيلية (المشاريع، العقارات، عقود الإيجار والفوترة، الجولات) في مستوى النموذج التفاعلي (Interactive Showcase Layers) بالاعتماد على منطق المتصفح أو خادم API وهمي مؤقت بدون إتمام دورة الربط الفعلي بقاعدة البيانات.
