ORCA CRM — تعليمات تشغيل إغلاق Revenue Integrity

شغّل الملف:
orca-revenue-integrity-full-closure.ps1

التعليمات الملزمة:
- شغّل الملف كما هو على فرع التكامل وقاعدة Dev فقط.
- ممنوع تعديل السكربت.
- ممنوع تعديل الكود.
- ممنوع تعديل schema.prisma.
- ممنوع إنشاء أو تعديل migrations.
- ممنوع استخدام SQL يدوي.
- ممنوع استخدام db push أو migrate reset.
- ممنوع الاتصال بقاعدة الإنتاج أو استخدام أسرار الإنتاج.
- لا تحاول إصلاح أي حاجز يظهر أثناء التشغيل.
- لا تعتبر 401 أو 307 أو 500 نجاحًا.
- لا تعتبر فحص الكود أو Build وحده إغلاقًا.
- أعد ملفات النتائج كاملة دون اختصار:
  1. FINAL-REPORT.md
  2. FINAL-REPORT.json
- أرفق أيضًا مسارات logs الناتجة عن التشغيل.
- الحكم المقبول فقط كما يصدره السكربت:
  READY_FOR_MANUAL_INTEGRATION
  أو
  NOT_READY_FOR_MANUAL_INTEGRATION

ممنوع تغيير نتيجة السكربت أو إعادة صياغتها.
