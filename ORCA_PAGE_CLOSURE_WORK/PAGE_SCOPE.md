
# ORCA Page Closure Work Scope



## الصفحات المخصصة للوكيل



1. أداء المبيعات

2. الإعلان والتسويق

3. الحملات

4. الوكلاء

5. الدعم والمهام

6. مستودع المستندات

7. البريد الإلكتروني

8. واتساب

9. الإعدادات



## حدود النطاق



- يعمل الوكيل على الصفحات المذكورة فقط.

- يمنع تعديل Dashboard أو أي صفحة أخرى غير مدرجة.

- يمنع التوسع إلى APIs أو قاعدة البيانات أو المسارات المشتركة دون موافقة صريحة.

- يمنع Commit أو Push أو Deploy أو Migration.

- لا يبدأ التنفيذ قبل اعتماد طريقة العمل ومعايير الإغلاق.

- أي ملف مشترك قد يؤثر في صفحات أخرى يتطلب موافقة قبل تعديله.
