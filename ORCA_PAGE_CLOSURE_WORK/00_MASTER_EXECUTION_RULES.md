
# ORCA PAGE CLOSURE — MASTER EXECUTION RULES



## هدف هذا المجلد

هذا المجلد هو مساحة توجيه الوكيل البرمجي لإغلاق الصفحات البسيطة فقط، بعقود تصميم وتنفيذ مغلقة.



## قاعدة العمل

- صفحة واحدة = عقد واحد = تنفيذ واحد = تحقق بصري واحد = اختبار مستهدف واحد.

- لا يعمل الوكيل حسب اجتهاده.

- لا يبدأ أي صفحة قبل اكتمال PAGE_CONTRACT.md الخاص بها واعتماده.

- لا ينتقل إلى صفحة أخرى تلقائيًا.

- لا يفتح Dashboard أو الصفحات الثقيلة أو أي نطاق غير مذكور.



## الصفحات المخصصة للوكيل

1. أداء المبيعات

2. الإعلان والتسويق

3. الحملات

4. الوكلاء

5. الدعم والمهام

6. مستودع المستندات

7. البريد الإلكتروني

8. واتساب

9. الإعدادات



## الصفحات خارج نطاق الوكيل

- Dashboard مغلقة ولا تفتح.

- أي صفحة تشغيلية ثقيلة أو مالية أو مرتبطة بالعقود والمدفوعات خارج النطاق إلا بتوجيه مستقل.

- أي API أو قاعدة بيانات أو Migration خارج النطاق.



## قواعد نظام التصميم

- RTL عربي كامل.

- لا UUID أو معرفات تقنية ظاهرة.

- Primary: أزرق تشغيلي.

- Accent: ذهبي محدود للتمييز فقط.

- Secondary: زر بحد.

- Ghost: شفاف.

- ارتفاع الأزرار لا يقل عن 44px.

- الكروت متساوية الارتفاع.

- الجداول داخل كروت بارتفاع ثابت وتمرير داخلي مخفي الشريط.

- Empty States عربية واضحة.

- Light/Dark من نفس tokens.

- لا ألوان Hex جديدة.

- لا Hover يسبب تمدد أو Layout Shift.

- لا Scrolll مزدوج.

- لا بيانات وهمية.



## قيود Git وبيئة العمل

- يبدأ دائمًا بـ git status.

- ممنوع reset / clean / stash.

- ممنوع Commit / Push / Deploy / Migration.

- أي ملف مشترك يتطلب موافقة قبل تعديله.



## مخرجات الوكيل

في نهاية كل صفحة يكتب فقط:

- الملفات المعدلة.

- ما تم تنفيذه حسب العقد.

- نتيجة الاختبار المستهدف.

- تأكيد عدم وجود Commmit/Push/Deploy.

- READY_FOR_VISUAL_VERIFICATION
